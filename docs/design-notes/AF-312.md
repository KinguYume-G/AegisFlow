# Design Note — AF-312 Gate 2 reliability report and blog

**Status:** Approved v1 — Project Owner approved 2026-08-03
**Issue:** AF-312 / GitHub #42

## Problem

M3 now has merged implementations and real execution evidence, but Gate 2 cannot be claimed from implementation or CI status alone. A reviewed evidence package must distinguish measured results from deterministic tests, disclose limitations, and provide a repeatable demo path without exposing credentials or model output.

## Objective

Publish a concise Gate 2 evidence package containing:

- an engineering reliability report;
- a reader-facing technical blog;
- a deterministic demo/runbook;
- immutable links to the merged implementation, GitHub Actions runs, and redacted artifact metadata.

## Non-Goals

- No application, workflow, model-routing, database, or infrastructure code changes.
- No new reliability claims beyond collected evidence.
- No claim that a real provider outage occurred: the protected provider smoke exercised the primary route only.
- No M4 implementation, release tag, deployment, or Issue closure before Human Review/Merge.

## Proposed Flow

1. Record PR #100 and merge commit `5a5b6a33e4cdf0750a5e3f2d86ddf0766c06d016` as the implementation baseline.
2. Record real Gate 2 fault run `30801262477` and its artifact metadata.
3. Record protected model smoke run `30804037539` using model identifiers only.
4. Separate evidence classes:
   - real hosted execution;
   - deterministic unit/integration/fallback tests;
   - explicit untested limitations.
5. Publish a copy-paste-safe demo sequence that references GitHub workflows and never requests Secret values.
6. Stop at a PR for Human Review; Gate 2 passes only after the reviewer accepts the report and limitations.

## State Ownership

PostgreSQL and Temporal ownership remain unchanged. GitHub Actions owns ephemeral run logs/artifacts; the repository owns the reviewed report and immutable evidence links.

## External Side Effects

No additional external write is required during implementation. Re-running either manual workflow is an explicit operator action and may incur a small provider charge.

## Idempotency

Documentation generation is deterministic. Evidence is keyed by immutable run ID, artifact ID, merge commit, and model identifier. Re-running workflows creates new evidence rather than overwriting prior evidence.

## Failure Modes

- Expired artifact: retain run ID, metrics, artifact name/ID, and reproducibility commands in the report.
- Provider configuration removed: disclose it; do not convert a historical success into a current availability claim.
- Primary-only smoke: report only primary success; cite deterministic tests for fallback behavior.
- Metrics disagree across local and hosted runs: publish both with environment labels; hosted evidence controls Gate 2.
- Broken or private links: preserve repository-relative instructions and GitHub run IDs.

## Security Impact

- No API Key, model response body, prompt content beyond the fixed non-sensitive smoke prompt, or local path is published.
- Only model identifiers, route outcomes, token measurement state, cost source, timing aggregates, and run metadata may appear.
- Logs and documents receive an explicit Secret-pattern scan.

## Observability

The report records hosted run status, duration, 20-run p50/p95, duplicate-effect count, lost-Signal count, resolved model, route chain, token status, and cost-source classification.

## Documentation Updates

Add the three Gate 2 artifacts and synchronize `docs/index.md`, `docs/21_TRACEABILITY_MATRIX.md`, `docs/24_REPOSITORY_LAYOUT.md`, and `MANIFEST.md`.

## Rollback

Revert the documentation commit. No runtime, database, workflow, Secret, or external system rollback is required.

## Resolved Decisions

1. The hosted fault run is the authoritative recovery evidence.
2. The provider smoke proves a real primary-provider request, measured usage, and provider-reported cost; it does not prove a real provider outage.
3. Fallback and circuit behavior are supported by deterministic tests, not misrepresented as a live outage.
4. Gate 2 acceptance remains a Human Review decision after the report PR merges.
