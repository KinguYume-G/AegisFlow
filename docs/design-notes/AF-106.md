## Problem and Objective

Planner 需要能区分“仓库证据”与“无证据推断”的 ContextPackage。AF-106 提供只读、有限、确定性的本地 fixture Retriever，验证引用契约而不提前接入 GitHub API 或向量检索。

## Non-Goals

不调用网络、GitHub API、数据库、向量服务或模型；不做语义总结，不修改被检索文件。

## Design

`CitedSnippet`、`ContextPackage`、root containment、文件/大小/数量限制、评分和排序算法完整定义在共享契约第 6 节。

```text
class ContextRetriever(Protocol):
    def retrieve(request: NormalizedRequest) -> ContextPackage: ...

class LocalFixtureContextRetriever:
    def __init__(self, root: Path): ...

class ContextAgent:
    def __init__(self, retriever: ContextRetriever): ...
    def gather(request: NormalizedRequest) -> ContextPackage: ...
```

root 和 Retriever 都必须显式注入；生产包中不得硬编码 `tests/`。所有匹配结果按 score/path 稳定排序，最多 5 条。

## Failure and Security

- root 不存在或不是目录时立即失败。
- symlink、越界路径、超大文件、不支持扩展名和超过扫描上限的候选均不读取。
- 无命中是合法结果：空 snippets + unsupported note，不编造引用。
