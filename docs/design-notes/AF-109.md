# Design Note — AF-109 Add initial Langfuse tracing and cost fields

> 状态：**Draft v4**，等待 Human Review。依赖 AF-104–AF-107 Human Merge；按 Bundle 顺序 AF-108 也应完成。

## Problem and Objective

M1 需要可关联、可脱敏且诚实表达 token/cost 未测量状态的节点 Trace。AF-109 提供 Recorder 端口、内存/禁用/Langfuse 实现以及一条使用真实开发环境的人工 smoke workflow。

## Non-Goals

- 标准 pytest/PR CI 不连接 Langfuse、不读取真实 Secret。
- 不宣称 Langfuse observation 服务端强幂等；Python SDK v4 不支持自定义 observation ID。
- 不生成虚假的 token/cost，不实现 OTel/Prometheus 完整平台。
- 不修改 AF-104–AF-108 已交付的 Agent 公共接口。

## Trace Contract

完整 Schema 见共享契约第 9 节：六项 ADR-0008 correlation 字段、AegisFlow event_id、非负整数 TokenMeasurement、finite 非负 Decimal CostUsage、redacted prompt 和非负 latency。

`event_id` 是稳定的 AegisFlow metadata，不冒充 Langfuse observation ID。Langfuse trace ID 使用 `Langfuse.create_trace_id(seed=str(trace_id))`。Recorder 每次调用最多尝试记录一次，不自动重试；Trace 是非权威 best-effort telemetry，不影响业务结果。

```text
class TraceRecorder(Protocol): record(step) -> None
class NoOpTraceRecorder: 不记录
class InMemoryTraceRecorder: 保存 defensive copy
class LangfuseTraceRecorder: 创建并结束 observation；event_id 放 metadata
```

本地组装异常只记录 `type(exc).__name__`，不记录异常消息、堆栈、请求、响应或配置值。`redact()` 至少覆盖 bearer/API key、PEM、email、URI credentials 和常见 secret assignment；先脱敏再构造 StepTraceRecord。

## Configuration

以下四项全无时使用 NoOp，全有时启用 Langfuse，任何部分配置都抛 `ConfigurationError`：

- `LANGFUSE_BASE_URL`
- `LANGFUSE_PUBLIC_KEY`
- `LANGFUSE_SECRET_KEY`
- `LANGFUSE_TRACING_ENVIRONMENT`

`.env.example` 使用占位符，不包含真实凭证。

## Real Smoke Workflow

`.github/workflows/langfuse-smoke.yml` 仅 `workflow_dispatch`，固定入口 `uv run python -m aegisflow_core.runtime.langfuse_smoke`，引用已经配置的 `langfuse-development` Environment。Actions 使用与 CI 相同的 SHA-pinned checkout/setup-uv、Python 3.12、`uv sync --locked`、最小 `contents: read` 权限。

入口必须执行：`auth_check()` → 创建/结束哨兵 observation → `flush()` → 最多 60 秒、每 2 秒一次按 deterministic trace ID 查询 observation API。任一步失败或超时都退出 1。生产 Recorder 的 best-effort 行为不得让 smoke 假通过；smoke 直接检查认证、flush 和查询结果。

## Failure and Security

- 部分配置 fail-fast；普通 PR 不获得 Environment Secret。
- SDK/mock 异常不得把伪造凭证写入日志。
- 真实 smoke 不打印 Secret；哨兵只含固定无敏感文本和 GitHub run correlation metadata。
- SDK 不支持的 observation-ID upsert 不作为验收条件。
