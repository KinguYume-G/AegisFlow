# Test Plan — AF-105 Implement Clarifier Agent contract

> 状态：**Draft v4**。配套 [`../design-notes/AF-105.md`](../design-notes/AF-105.md)。

## Scope and Strategy

验证 Clarification Schema、五条固定判断规则、Agent 显式注入与 resolve 算法。全部为无外部依赖单元测试。

## Required Tests

| Test | Required assertion |
|---|---|
| `test_question_validates_field_and_length` | snake_case/长度限制生效 |
| `test_clarification_rejects_duplicate_fields` | 重复 question field 被拒绝 |
| `test_clarification_state_invariants` | sufficient/questions/answers 的所有矛盾组合被拒绝 |
| `test_answers_limits` | 50 项、每值 8,192 边界成功；超限失败 |
| `test_reasoner_rule_authorized_roles` | 缺显式排他授权时产生固定问题 |
| `test_reasoner_rule_time_range` | 缺默认/最大范围时产生固定问题 |
| `test_reasoner_rule_record_limit` | 缺数值上限时产生固定问题 |
| `test_reasoner_rule_output_and_redaction` | 缺列或脱敏任一信息时产生固定问题 |
| `test_reasoner_rule_delivery_mode` | 缺同步/异步边界时产生固定问题 |
| `test_reasoner_question_order_is_stable` | 多项缺失时严格按契约表顺序 |
| `test_reasoner_accepts_complete_request` | 五项证据齐全时 sufficient、空 questions |
| `test_agent_requires_reasoner_and_propagates_error` | 无默认 fake，异常不吞掉 |
| `test_resolve_complete_answers` | 清空 questions、sufficient、保留全部 answers |
| `test_resolve_missing_or_blank_answers` | 排序后的 missing fields 错误 |
| `test_resolve_preserves_bounded_extras` | 合法额外答案保留 |
| `test_resolve_never_reinvokes_reasoner` | spy 调用数不增加 |

模块边界：clarifier 不导入 Web、LangGraph、Temporal 或 provider SDK。

## Commands

```bash
uv run --locked python -m pytest tests/packs/delivery/clarifier -v
uv run --locked python -m pytest -v
```

## Pass/Fail and Evidence

规则顺序、答案保留、Schema 不变量或异常传播任一失败即阻塞。实现 PR 填写真实 Evidence。

## Limitations

固定规则不能替代真实模型的语义理解；不测试 HITL Gateway 或 durable resume。
