# Test Plan — AF-107 Implement Planner Agent contract

> 状态：**Draft v4**。配套 [`../design-notes/AF-107.md`](../design-notes/AF-107.md)。

## Scope and Strategy

验证 Measurement/Plan Schema、稳定能力枚举、固定四任务 Reasoner 和 Planner 拒绝路径。纯单元测试。

## Required Tests

| Test | Required assertion |
|---|---|
| `test_measurement_not_available_invariant` | value/unit 必须同时为空 |
| `test_measurement_measured_invariant` | finite、非负 Decimal 和 unit 必填 |
| `test_measurement_rejects_negative_nan_infinity` | 非法数值全部拒绝 |
| `test_tool_capability_v1_exact_set` | 只接受五个稳定能力名，供应商名被拒绝 |
| `test_plan_task_requires_structured_tools` | 裸字符串不可替代 ToolRequirement |
| `test_reasoner_emits_four_ordered_tasks` | 读取、实施、测试、Draft PR 顺序与能力准确 |
| `test_reasoner_assigns_l3_for_sensitive_markers` | tenant/权限/Secret/支付/审计任一命中为 L3 |
| `test_reasoner_assigns_l1_otherwise` | 非敏感输入为 L1 |
| `test_reasoner_marks_missing_repository_evidence` | 无 snippets 时不编造引用并明确证据缺失 |
| `test_budget_is_not_available` | 无虚假预算数值 |
| `test_planner_rejects_insufficient_clarification` | 不越过 Clarifier gate |
| `test_agent_requires_reasoner_and_propagates_error` | 无默认 fake，异常透传 |
| `test_instruction_like_context_cannot_expand_capabilities` | 不可信引用不能改变算法/枚举 |

模块边界：planner 不导入 Web、LangGraph、Policy/MCP 或 provider SDK。

## Commands

```bash
uv run --locked python -m pytest tests/packs/delivery/planner -v
uv run --locked python -m pytest -v
```

## Pass/Fail and Evidence

自由文本工具、虚假预算、Gate 绕过或不稳定输出均为阻塞。实现 PR 填写真实 Evidence。

## Limitations

能力枚举 v1 是稳定抽象但尚未映射 AF-406 Registry；本测试不验证真实权限或工具执行。
