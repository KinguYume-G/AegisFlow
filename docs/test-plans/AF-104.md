# Test Plan — AF-104 Implement Intake Agent contract

> 状态：**Draft v4**。配套 [`../design-notes/AF-104.md`](../design-notes/AF-104.md)。

## Scope and Strategy

纯单元测试，测试先于实现；不使用网络、数据库或真实时间。验证 Schema、规范化、内容幂等键与 Clock/IdGenerator 具体实现。

## Required Tests

| Test | Required assertion |
|---|---|
| `test_fixed_clock_returns_aware_utc_constant` | 多次返回同一 timezone-aware UTC 值 |
| `test_sequential_id_generator_reproducible` | 相同 seed 的两个实例产生相同 UUID5 序列 |
| `test_normalized_request_accepts_all_source_types` | 四个 source type 均合法 |
| `test_request_rejects_empty_title_and_body` | 规范化后同时为空被拒绝 |
| `test_request_enforces_exact_length_limits` | source_ref 2,048、title 500、body 1,000,000 边界成功；+1 失败 |
| `test_request_rejects_naive_received_at` | naive datetime 被拒绝 |
| `test_normalization_nfkc_newlines_and_whitespace` | NFKC、换行、行内/行边空白规则逐项符合契约 |
| `test_idempotency_key_matches_canonical_sha256` | 与独立计算的 canonical JSON SHA-256 完全一致 |
| `test_idempotency_ignores_ref_and_clock` | 内容相同但 ref/time 不同仍同 key |
| `test_idempotency_changes_with_type_or_content` | source type 或规范化内容变化导致不同 key |
| `test_intake_requires_only_clock` | 无 Clock 构造失败；不接收/不持有 id_generator |
| `test_prompt_like_body_is_data_only` | 指令样式文本只被规范化，不执行 |

模块边界：intake/contracts 不导入 FastAPI、LangGraph、Temporal、数据库或 provider SDK。

## Commands

```bash
uv run --locked python -m pytest tests/packs/delivery/intake -v
uv run --locked python -m pytest -v
```

## Pass/Fail and Evidence

任一边界、哈希或模块依赖断言失败即阻塞。PR 记录命令、通过数量、coverage、锁文件 diff 和未运行项；Evidence 在实现 PR 中填写。

## Limitations

不证明持久去重、Webhook 解析或语义等价检测；这些不属于 AF-104。
