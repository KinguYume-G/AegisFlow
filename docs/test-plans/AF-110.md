# Test Plan — AF-110 Build Gate 1A end-to-end test

> 状态：**Draft v4**。配套 [`../design-notes/AF-110.md`](../design-notes/AF-110.md)。

## Scope and Strategy

使用固定脱敏 fixture、显式 fake、`InMemorySaver`、InMemory HITL/Trace，验证 Gate 1A 进程内链路。禁止真实网络、Langfuse、数据库或模型调用。

## Fixture Validation

- `sample_request.json` 映射 Raw Request、Existing Context 摘要、Acceptance Criteria、Sanitization Record。
- `expected_clarification.json` 精确包含五个固定 field/question，顺序一致。
- `fixed_clarification_response.json` 保存七项非空回答。
- context fixtures 分别覆盖 tenant isolation、Celery async export、audit/security。
- 迁移完成后根目录 `gemini-code-1785679381247.md` 不存在，三个 JSON 已被 Git 跟踪；不要求不存在的 deletion diff。

## Required Tests

| Test | Required assertion |
|---|---|
| `test_agent_state_requires_run_and_trace_identity` | run_id/trace_id 与业务字段 shape 正确 |
| `test_graph_requires_all_explicit_dependencies` | 省略任何端口都无法组装 |
| `test_fixture_triggers_real_interrupt` | 首次 invoke 返回 interrupt，未产生 Plan |
| `test_resume_with_answers_completes_plan` | 同一 run/thread + Command 恢复，answers 保留并生成 Plan |
| `test_resume_calls_resolve_not_reasoner` | resolve 一次，Reasoner 不复核 |
| `test_incomplete_answers_do_not_pass_gate` | 明确错误，无 Context/Plan |
| `test_wrong_thread_is_rejected_before_resume` | `InvalidResumeThreadError`，原 checkpoint/Plan 不变 |
| `test_completed_thread_cannot_resume_again` | 重复恢复被拒绝，无第二个 Plan |
| `test_request_replay_reuses_hitl_request` | Clarifier replay 仍只有一个 request_id |
| `test_context_has_valid_nonempty_citation` | 引用来自受限 fixture root，行号/原文一致 |
| `test_plan_matches_fixed_four_task_contract` | 顺序、capabilities、L3 风险和 not_available budget 正确 |
| `test_trace_one_completion_record_per_node` | 四节点各一条逻辑完成 Trace，Clarifier replay 不重复 |
| `test_trace_correlation_and_usage` | 六项字段、event_id、fake usage 结构正确，共享 run/trace |
| `test_two_fresh_runs_are_reproducible` | 重置相同 fake 后，除 latency 外逐字段相等 |
| `test_each_node_failure_is_locatable` | 四节点分别注入异常，返回正确 node/cause_type |
| `test_no_external_clients_are_called` | 网络/DB/Langfuse/model 均为零调用 |

```bash
uv run --locked python -m pytest tests/e2e/test_gate1a.py -v

```

## Pass/Fail and Evidence

未真实 interrupt/resume、错误 thread 越权恢复、答案丢失、重复逻辑 Trace、空/伪造 citation、结果不确定或任何外部调用均为阻塞。PR 保存 fixture 映射清单、API 版本核实说明、命令与结果。

## Limitations

只验证单进程内存路径；不证明跨重启恢复、Temporal、PostgresSaver、Policy Gate、Executor 或 Reviewer。
