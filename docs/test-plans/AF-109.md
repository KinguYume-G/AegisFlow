# Test Plan — AF-109 Add initial Langfuse tracing and cost fields

> 状态：**Approved v4 / Execution in progress**。配套 [`../design-notes/AF-109.md`](../design-notes/AF-109.md)。

## Scope and Strategy

标准测试全部使用 mock，不访问 Langfuse。真实 SaaS 证据来自 Human Merge 后手动 `langfuse-smoke.yml`。

## Required Unit Tests

| Test | Required assertion |
|---|---|
| `test_trace_has_six_correlation_fields_and_event_id` | 字段存在、类型/可空性正确 |
| `test_event_id_is_deterministic_metadata` | 相同 correlation 输入同 UUID；不作为 observation ID 参数 |
| `test_token_measurement_invariants` | measured 为非负整数；not_available 为 None |
| `test_token_usage_rejects_invalid_total` | measured total 必须等于 input+output |
| `test_cost_usage_invariants` | finite 非负 Decimal、三字母大写 currency、状态组合正确 |
| `test_fake_usage_is_not_available` | fake 不产生估算 token/cost |
| `test_redact_each_required_pattern` | bearer/key/PEM/email/URI credential/assignment 均脱敏 |
| `test_redact_preserves_safe_text_and_bounds_input` | 正常文本保留，超长输入安全处理 |
| `test_settings_all_absent_is_noop` | 四字段全无返回 NoOp |
| `test_settings_all_present_is_langfuse` | 四字段全有返回 Langfuse recorder |
| `test_settings_any_partial_combination_fails` | 1/2/3 项存在的组合全部 fail-fast |
| `test_noop_has_no_effect` | 不保存、不调用 SDK |
| `test_inmemory_returns_defensive_copy` | 顺序稳定，外部不能修改内部列表 |
| `test_langfuse_uses_deterministic_trace_id_and_event_metadata` | mock 断言 trace seed 与 metadata；未传 custom observation ID |
| `test_langfuse_makes_no_automatic_retry` | SDK 失败时调用次数恰为 1 |
| `test_local_error_log_contains_only_exception_type` | 不含消息、堆栈或伪造 Secret |

## Workflow Static Tests/Review

- YAML 只含 `workflow_dispatch`，environment 精确为 `langfuse-development`。
- Secrets/Variables 名称正确，权限只有 `contents: read`，Actions SHA 固定。
- 固定模块入口存在，代码顺序包含 auth_check、end、flush、60 秒 bounded query。
- 生产 Recorder 的异常策略不参与 smoke 成功判定。

```bash

```

## Pass/Fail and Evidence

任何真实网络出现在 pytest、日志泄密、伪造计量、自定义 observation-ID 假设或 smoke 假绿灯均为阻塞。最终证据包括 CI URL、smoke Actions URL 与可查询 trace ID；不得记录 Secret。

Pre-PR 本地证据：锁定 `langfuse==4.14.2`；216 tests 通过，branch coverage 95.77%；真实 PostgreSQL migration up/check/down/re-up 通过；Core runtime 镜像构建通过。普通 pytest 显式移除全部 Langfuse 配置；真实 SaaS smoke 仍须在 Human Merge 后由 Project Owner 手动触发。

## Limitations

不保证 Langfuse observation 服务端强幂等。Telemetry 不是业务事实源，不验证生产流量、计费精度或长期可用性。
