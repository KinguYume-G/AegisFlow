# Test Plan — AF-108 Implement clarification HITL interface

> 状态：**Draft v4**。配套 [`../design-notes/AF-108.md`](../design-notes/AF-108.md)。

## Scope and Strategy

验证 `packs/delivery/clarifier/hitl.py` 的进程内状态机、run 隔离与 LangGraph replay 所需的 request 幂等性。纯单元测试。

## Required Tests

| Test | Required assertion |
|---|---|
| `test_request_creates_pending_record` | request ID、run、step、questions 正确保存 |
| `test_request_is_idempotent_for_run_and_step` | 重复调用返回同 ID，记录数仍为 1 |
| `test_request_does_not_reset_answered_record` | replay 不覆盖已回答状态/答案 |
| `test_different_run_or_step_is_distinct` | 两个幂等键维度都有效 |
| `test_gateway_uses_injected_id_generator` | ID 序列可重复，无内部 uuid4 |
| `test_submit_transitions_pending_to_answered` | 状态原子转换，答案 defensive copy |
| `test_submit_rejects_unknown_request` | 独立异常，状态不变 |
| `test_submit_rejects_run_mismatch` | 跨 run 回复失败，原记录不变 |
| `test_submit_rejects_duplicate_response` | 第二次回答失败且首个答案不被覆盖 |
| `test_get_status_rejects_unknown_request` | 未知 ID 不静默返回 |
| `test_instruction_like_answer_is_stored_not_executed` | 文本只作为数据 |

模块边界：`clarifier/hitl.py` 不导入 Web、LangGraph、Temporal 或数据库 SDK；确认不存在顶层 `packs/delivery/hitl.py`。

## Commands

```bash
uv run --locked python -m pytest tests/packs/delivery/clarifier/test_hitl.py -v
uv run --locked python -m pytest -v
```

## Pass/Fail and Evidence

重复请求产生新记录、跨 run 接受答案或重复提交覆盖首答均为阻塞。实现 PR 填写 Evidence。

## Limitations

只证明单进程行为；不证明通知、重启恢复、Temporal signal 或持久化。
