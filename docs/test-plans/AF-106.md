# Test Plan — AF-106 Implement Context Agent retrieval contract

> 状态：**Draft v4**。配套 [`../design-notes/AF-106.md`](../design-notes/AF-106.md)。

## Scope and Strategy

使用临时受控目录验证 Schema、确定性本地检索、引用行号与文件系统安全边界；禁止网络。

## Required Tests

| Test | Required assertion |
|---|---|
| `test_cited_snippet_validates_relative_path_and_lines` | 绝对/越界路径与反向行范围被拒绝 |
| `test_package_separates_snippets_and_unsupported_notes` | 两类内容不可互换 |
| `test_retriever_rejects_missing_or_file_root` | root 必须是存在目录 |
| `test_retriever_accepts_only_allowed_regular_files` | 仅 md/py/txt 普通文件 |
| `test_retriever_skips_symlink_and_escape` | symlink 与 resolve 后越界文件不读取 |
| `test_retriever_skips_file_over_256_kib` | 超限文件不读取 |
| `test_retriever_scans_at_most_200_files` | 扫描上限确定且可观察 |
| `test_retriever_scores_and_sorts_deterministically` | score desc/path asc，最多 5 条 |
| `test_retriever_reports_exact_first_match_lines` | 原文与 1-based 行号吻合，最多 5 行 |
| `test_retriever_no_match_is_explicit` | 空 snippets + unsupported note |
| `test_context_agent_requires_retriever` | 无默认 fake，异常透传 |

模块边界：context 不导入 Web、GitHub client、向量库、LangGraph 或 provider SDK。

## Commands

```bash
uv run --locked python -m pytest tests/packs/delivery/context -v
uv run --locked python -m pytest -v
```

## Pass/Fail and Evidence

越界读取、引用错误、非确定排序或伪造 snippet 任一发生即阻塞。实现 PR 填写真实 Evidence。

## Limitations

关键字重叠检索只用于 M1 契约验证，不代表生产级 GitHub/向量检索召回率。
