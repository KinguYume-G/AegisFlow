# 22 — Glossary

- **Agent Control Plane**：统一治理 Agent、模型、工具、权限、审批、评测与成本的管理平面。
- **DeliveryPack**：AegisFlow 首发应用包，覆盖需求到 Draft PR/部署。
- **Durable Execution**：故障后从持久历史恢复。
- **Checkpoint**：Agent 图状态快照。
- **HITL**：Human-in-the-loop。
- **MCP**：Model Context Protocol。
- **Policy Gate**：工具副作用前的确定性规则。
- **Idempotency**：重复请求不产生重复副作用。
- **Saga**：多步副作用失败后的补偿模式。
- **Golden Dataset**：固定、版本化、带真值的评测集。
- **Prompt Regression**：Prompt 新版本导致质量、安全或成本退化。
- **Contextual Policy Rules**：基于角色、资源、环境、风险和审批的确定性规则。
- **Dogfooding**：开发者长期使用自己的产品。
- **Gate**：必须通过的阶段验收门。
