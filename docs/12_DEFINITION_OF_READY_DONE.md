# 12 — Definition of Ready & Done

## Ready

- [ ] 目标和非目标明确
- [ ] 验收标准可测试
- [ ] 依赖完成
- [ ] 模块明确
- [ ] 风险和安全影响明确
- [ ] 测试类型明确
- [ ] 外部输入明确
- [ ] 一个 PR 内完成
- [ ] 符合冻结方向

## Done

- [ ] 满足验收
- [ ] 测试先行并通过
- [ ] 失败路径
- [ ] 安全测试（适用）
- [ ] 幂等测试（适用）
- [ ] 文档和 Traceability 更新
- [ ] 无 Secret
- [ ] 无无关重构
- [ ] Human Review
- [ ] PR Merge
- [ ] Gate Evidence（适用）
- [ ] 风险记录

## Gate Done

所有 P0 Issue Done、Gate 测试通过、文档一致、演示可重复、指标有环境和样本说明。
